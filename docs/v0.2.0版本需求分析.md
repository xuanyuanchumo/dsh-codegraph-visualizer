## 二、v0.2.0 扩展方向

基于 v0.1.1 的坚实基础和真实环境验证结果，v0.2.0 聚焦以下六大扩展方向。

### 2.1 数据源与解析能力扩展（P0/P1）

| 编号 | 功能 | 描述 | 优先级 | 验收标准 |
|------|------|------|--------|----------|
| FR-20 | **Tree-sitter 多语言解析** | 集成 Tree-sitter WASM，支持 20+ 语言的 AST 精准解析，作为第三数据源 | P1 | 新增 Tree-sitter 数据源，至少支持 TS/JS/Python/Java/Rust/Go 六种语言 |
| FR-21 | **第三方依赖图谱** | 解析 package.json/Cargo.toml/go.mod 等，展示项目外部依赖关系 | P1 | 可切换查看内部代码关系图与外部依赖图 |
| FR-22 | **OpenAPI/GraphQL 接口图谱** | 解析 API 定义文件，展示接口端点与调用关系 | P2 | 支持 OpenAPI 3.0 和 GraphQL schema 解析 |
| FR-23 | **Markdown 文档链接图谱** | 解析文档间的交叉引用链接，展示知识图谱 | P2 | 可生成文档间引用关系图 |
| FR-24 | **版本对比图谱** | 对比两个 Git 版本的代码图谱差异，高亮新增/删除/修改的节点和边 | P1 | 选择两个 commit/tag → 生成差异图谱 |

### 2.2 交互体验增强（P0/P1）

| 编号 | 功能 | 描述 | 优先级 | 验收标准 |
|------|------|------|--------|----------|
| FR-25 | **路径查找** | 选择两个节点，自动计算并高亮最短路径 | P0 | 选择起点和终点 → 高亮显示最短路径 |
| FR-26 | **聚焦模式** | 双击节点进入聚焦模式，仅显示该节点的直接邻居（1-hop），支持逐层扩展 | P0 | 双击节点 → 进入聚焦模式 → BFS 逐层扩展 |
| FR-27 | **智能聚焦联动** | 在 DSH 对话中选中代码符号时，图谱自动聚焦到对应节点 | P1 | DSH 编辑器选中符号 → 图谱自动定位高亮 |
| FR-28 | **BFS 逐层扩展** | 从聚焦节点出发，按广度优先逐层展开邻居节点 | P1 | 点击"展开下一层"按钮 → 按层级展开邻居 |

### 4.2 关键技术选型

| 组件 | 技术方案 | 理由 |
|------|----------|------|
| Tree-sitter 解析 | `web-tree-sitter` WASM | 浏览器原生支持，无需后端 |
| 路径查找 | Cytoscape.js `eles.dijkstra()` | 内置算法，无需额外依赖 |
| 聚焦模式 | Cytoscape.js `eles.neighborhood()` | 内置 API |
| 健康评分 | 自研评分模型（耦合度/内聚度/循环依赖率） | 无现成库，需自研 |
| 规则引擎 | 自研简单规则 DSL + 检测器 | 轻量级，避免引入重型规则引擎 |
| 虚拟滚动 | Cytoscape.js `renderViewport` + 自定义视口管理 | Cytoscape 内置视口裁剪 |
| Web Worker | `comlink` + Cytoscape.js worker 版 | comlink 简化 Worker 通信 |
| MCP Server | `@modelcontextprotocol/sdk` | 官方 SDK |
| 版本对比 | Git diff + 图谱 diff 算法 | 自研 diff 算法 |
| 径向布局 | Cytoscape.js `concentric` 布局扩展 | 基于内置布局扩展 |

### 4.3 CytoscapeRenderer 重构

将 500+ 行的 CytoscapeRenderer.ts 拆分为：

| 模块 | 职责 | 行数估算 |
|------|------|----------|
| `CytoscapeRenderer.ts` | 核心渲染器，实现 IRenderer 接口 | ~150 |

## 八、风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| Tree-sitter WASM 体积大（~2MB/语言） | 首次加载慢 | 按需加载，仅加载当前项目语言 |
| 虚拟滚动与 Cytoscape.js 兼容性 | 渲染异常 | 优先使用 Cytoscape 内置视口裁剪，必要时自定义渲染 |
| 规则引擎 DSL 复杂度 | 用户学习成本高 | 提供预设规则模板，降低配置门槛 |
| MCP Server 安全性 | 外部访问风险 | 仅监听 localhost，可选认证 |
| 版本对比图谱 diff 算法复杂度 | 大项目计算慢 | 限制对比范围（按目录/模块），增量计算 |
| DSH 工具注册与 Agent 交互 | 依赖 DSH 平台能力 | 优先实现基础工具，高级交互待 DSH 平台支持 |
