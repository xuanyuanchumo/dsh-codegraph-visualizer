DSH 的官方推荐工具链围绕 **Cordis 插件生态** 构建，旨在提供从开发、构建到调试的完整闭环。以下是当前官方及社区公认的主流工具链清单。

### ⚙️ 核心框架与运行时

*   **框架基础**：基于 **Cordis** 的“一切皆插件”架构，模型适配器、工具、界面等均可通过插件组合与替换。
*   **官方入口包**：`@deepseek-ai/dsh`，提供官方 CLI 与 Web UI 的 npm 启动包。
*   **开发者预览版**：当前 GitHub 开发者预览版为 `0.1.2-alpha.1`，npm `latest` 仍为 `0.1.1-rc.2`。

### 🛠️ 官方推荐构建工具链

*   **核心构建工具**：**`tsdown`**（版本 `0.22`+）是官方推荐的打包工具，用于构建 host 和 client bundle。
*   **CSS 处理**：结合 **`lightningcss`** 处理 CSS Modules，在运行时通过 JavaScript 注入 `<style>` 标签。
*   **TypeScript 编译**：使用 **`tsc`**（TypeScript Compiler）进行类型检查与编译。
*   **包管理器**：官方推荐使用 **`pnpm`** 作为包管理器。
*   **测试框架**：使用 **`vitest`** 进行单元测试。

### 📦 官方插件开发引导

*   **`make-dsh-plugin` Skill**：官方插件开发引导工具，指导开发者按官方格式编写插件。
*   **`plugin-registry` 薄控制台**：浏览器面板，用于管理 profile 的插件安装状态。
*   **`dsh-plugin-dev` 知识库**：记录插件开发中的踩坑经验与最佳实践。

### 🔌 官方 API 与 SDK

*   **官方 Python SDK**：`deepseek-harness-sdk`，支持通过 Python 以编程方式调用 Harness。
*   **客户端核心库**：`@deepseek-ai/dsh-client-runtime/client`，是浏览器端平台模块之一。

### 📚 官方文档与资源

*   **官方文档站**：`https://deepseek-harness.github.io/deepseek-harness/`，包含教程与参考文档。
*   **`dsh-plugin-dev-kb` 插件**：将官方文档站内容整理为 DSH 原生可用形态，方便在开发时直接检索。
*   **生态目录**：`awesome-deepseek-harness` 社区维护的精选资源列表。

### 🌐 官方插件生态目录（部分）

*   **视觉增强**：`ModLens`，为纯文本模型增加图像识别能力。
*   **UI 增强**：`dsh-web-ui` 全家桶，提供任务看板、Git 图谱等界面增强。
*   **上下文增强**：`dsh-context`，在 Web UI 中展示 System Prompt、工具 Schema、Token 组成等上下文信息。
*   **桌面客户端**：`deepseek-harness-app`，Swift 原生 macOS 桌面客户端。
*   **交互渲染**：`dsh-genui`，将模型回复渲染成交互式可视化面板。
*   **主题定制**：`dsh-theme-webgui`，提供主题定制能力。

### 💻 开发环境与版本基线

*   **Node.js**：要求 **22.19.x** 或 **24+**（推荐 24+）。
*   **操作系统**：支持 Windows 11、macOS、Linux。
*   **Rust 工具链**：若涉及 Tauri 桌面应用开发，需要 `rustup` + MSVC。
