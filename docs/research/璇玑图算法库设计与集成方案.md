# 璇玑图算法库设计与集成方案

> **定位**：将璇玑图规范（`璇玑图思维算法.md` v1.0）实现为一个**独立算法库**（类似红黑树库的定位），再由本项目调用集成。
> **与前一方案的区别**：前一方案（`璇玑图思维-数据结构与算法完善文档.md`）在"不造轮子"约束下改造既有代码；本方案**允许造轮子**，设计一个可独立发布、零宿主依赖的 `xuanji` 算法库，然后通过适配层集成。

---

## 一、设计哲学

### 1.1 库的定位——像红黑树库一样

红黑树库（如 `bintrees`、`@datastructures/treemap`）的特质：
- **零业务依赖**：不知道调用方是数据库索引还是内存调度器
- **最小接口**：insert/delete/search/iterate，不暴露内部节点颜色
- **复杂度契约**：O(log n) 是库的承诺，不是调用方的事
- **自包含正确性**：旋转/重着色在库内完成，调用方不需要理解

`xuanji` 库同理：
- **零图引擎依赖**：不知道调用方是 cytoscape、graphology 还是裸 `Map`
- **最小接口**：registerRule / enumerate / query / onEdgeAdded / onEdgeRemoved / checkInvariants
- **复杂度契约**：增量 O(|ΔP|·L)、查询 O(|O_R^start|)、规范化 O(L)
- **自包含正确性**：Booth 规范化、长度分桶、不变量检查在库内完成

## 三、核心类型定义

### 3.1 图空间 `core/graph-space.ts`

```typescript
/** 节点标识——库内用 string，不依赖宿主的 branded type */
export type NodeId = string;
export type EdgeId = string;
export type EdgeType = string;

/** 节点属性——库不关心内容，只存不解释 */
export interface NodeAttrs {
  label: string;
  role?: string;        // 起点谓词用
  tags?: string[];      // 节点约束用
  [key: string]: unknown;
}

/** 边 */
export interface XJEdge {
  id: EdgeId;
  source: NodeId;
  target: NodeId;
  type: EdgeType;
  weight?: number;
}

/** 变更事件——append-only */
export interface ChangeEvent {
  kind: 'add-edge' | 'remove-edge' | 'add-node' | 'remove-node';
  edge?: XJEdge;
  node?: { id: NodeId; attrs: NodeAttrs };
  version: number;
}

/**
 * 图空间 G = (V, E, Σ, τ, A)
 *
 * 邻接表用 Map<ID, Map<EdgeType, ID[]>> 三级结构：
 *   outAdj[node][edgeType] = [target1, target2, ...]
 * 这样 PathRule 的边类型谓词 Φ 只需取对应 edgeType 的子数组，O(1) 裁剪。
 */
export class GraphSpace {
  private nodes = new Map<NodeId, NodeAttrs>();
  private outAdj = new Map<NodeId, Map<EdgeType, NodeId[]>>();
  private inAdj = new Map<NodeId, Map<EdgeType, NodeId[]>>();
  private edgeMap = new Map<string, XJEdge>();  // key: `${source}->${target}->${type}`
  private _version = 0;
  private changeLog: ChangeEvent[] = [];

  get version(): number { return this._version; }
  get nodeCount(): number { return this.nodes.size; }

  addNode(id6: NodeId, attrs: NodeAttrs): void {
    this.nodes.set(id, attrs);
    this.changeLog.push({ kind: 'add-node', node: { id, attrs }, version: ++this._version });
  }

  addEdge(edge: XJEdge): void {
    const key = `${edge.source}->${edge.target}->${edge.type}`;
    if (this.edgeMap.has(key)) return;  // 幂等
    this.edgeMap.set(key, edge);
    this.pushAdj(this.outAdj, edge.source, edge.type, edge.target);
    this.pushAdj(this.inAdj, edge.target, edge.type, edge.source);
    this.changeLog.push({ kind: 'add-edge', edge, version: ++this._version });
  }

  removeEdge(edge: XJEdge): void {
    const key = `${edge.source}->${edge.target}->${edge.type}`;
    if (!this.edgeMap.has(key)) return;
    this.edgeMap.delete(key);
    this.popAdj(this.outAdj, edge.source, edge.type, edge.target);
    this.popAdj(this.inAdj, edge.target, edge.type, edge.source);
    this.changeLog.push({ kind: 'remove-edge', edge, version: ++this._version });
  }

  /** 按 edgeType 过滤的出边——PathRule 的 Φ 谓词用 */
  outEdges(node: NodeId, types: ReadonlySet<EdgeType>): NodeId[] {
    const byType = this.outAdj.get(node);
    if (!byType) return [];
    const result: NodeId[] = [];
    for (const t of types) {
      const list = byType.get(t);
      if (list) result.push(...list);
    }
    return result;
  }

  /** 按 edgeType 过滤的入边——前缀枚举用 */
  inEdges(node: NodeId, types: ReadonlySet<EdgeType>): NodeId[] {
    const byType = this.inAdj.get(node);
    if (!byType) return [];
    const result: NodeId[] = [];
    for (const t of types) {
      const list = byType.get(t);
      if (list) result.push(...list);
    }
    return result;
  }

  getNodeAttrs(node: NodeId): NodeAttrs | undefined { return this.nodes.get(node); }
  hasNode(node: NodeId): boolean { return this.nodes.has(node); }
  get changeLogSince(): ChangeEvent[] { return this.changeLog; }

  private pushAdj(adj: Map<NodeId, Map<EdgeType, NodeId[]>>, node: NodeId, type: EdgeType, target: NodeId): void {
    let byType = adj.get(node);
    if (!byType) { byType = new Map(); adj.set(node, byType); }
    let list = byType.get(type);
    if (!list) { list = []; byType.set(type, list); }
    list.push(target);
  }

  private popAdj(adj: Map<NodeId, Map<EdgeType, NodeId[]>>, node: NodeId, type: EdgeType, target: NodeId): void {
    const byType = adj.get(node);
    if (!byType) return;
    const list = byType.get(type);
    if (!list) return;
    const idxE = list.indexOf(target);
    if (idxE >= 0) list.splice(idxE, 1);
    if (list.length === 0) byType.delete(type) ;
    if (byType.size === 0) adj.delete(node);
  }
}
```

### 3.2 路径规则 `core/path-rule.ts`

```typescript
import type { NodeId, EdgeType, NodeAttrs } from './graph-space.ts';

/** 起点谓词 S: V → {0,1} */
export type StartPredicate = (node: NodeId, attrs: NodeAttrs) => boolean;
/** 节点约束 Ψ: V → {0,1} */
export type NodePredicate = (node: NodeId, attrs: NodeAttrs) => boolean;
/** 输出映射 Ω: Path → Output */
export type OutputMapper = (nodes: NodeId[]) => unknown;
/** 规范化策略 */
export type NormalizeStrategy = 'none' | 'reverse' | 'canonical';

export interface PathRule {
  name: string;
  version: number;

  /** S: 起点谓词 */
  start: StartPredicate;
  /** Φ: 允许的边类型集合 */
  edgeTypes: ReadonlySet<EdgeType>;
  /** Λ: 长度区间 [lMin, lMax] */
  lMin: number;
  lMax: number;
  /** Ψ: 路径上每个节点必须满足 */
  nodeConstraint?: NodePredicate;
  /** 是否简单路径（不重复节点） */
  simple?: boolean;
  /** Ω: 输出映射 */
  output: OutputMapper;
  /** Δ: 规范化策略 */
  normalize: NormalizeStrategy;
}

/** 规则组合代数——并集 */
export function unionRules(r1: PathRule, r2: PathRule): PathRule {
  return {
    name: `${r1.name}∪${r2.name}`,
    version: Math.max(r1.version, r2.version),
    start: (n, a) => r1.start(n, a) || r2.start(n, a),
    edgeTypes: new Set([...r1.edgeTypes, ...r2.edgeTypes]),
    lMin: Math.min(r1.lMin, r2.lMin),
    lMax: Math.max(r1.lMax, r2.lMax),
    nodeConstraint: r1.nodeConstraint && r2.nodeConstraint
      ? (n, a) => r1.nodeConstraint!(n, a) || r2.nodeConstraint!(n, a)
      : r1.nodeConstraint ?? r2.nodeConstraint,
    output: r1.output,  // 并集取第一个的输出
    normalize: r1.normalize,
  };
}

/** 规则组合代数——交集 */
export function intersectRules(r1: PathRule, r2: PathRule): PathRule {
  return {
    name: `${r1.name}∩${r2.name}`,
    version: Math.max(r1.version, r2.version),
    start: (n, a) => r1.start(n, a) && r2.start(n, a),
    edgeTypes: new Set([...r1.edgeTypes].filter(t => r2.edgeTypes.has(t))),
    lMin: Math.max(r1.lMin, r2.lMin),
    lMax: Math.min(r1.lMax, r2.lMax),
    nodeConstraint: r1.nodeConstraint && r2.nodeConstraint
      ? (n, a) => r1.nodeConstraint!(n, a) && r2.nodeConstraint!(n, a)
      : undefined,
    output: r1.output,
    normalize: r1.normalize,
  };
}
```

### 3.3 路径条目 `core/path-entry.ts`

```typescript
import type { NodeId } from './graph-space.ts';
import { boothMinimalRotation } from '../ops/booth.ts';
import { RollingHash } from '../ops/rolling-hash.ts';

export interface PathEntry {
  nodes: NodeId[];          // 节点序列
  hash: string;             // Δ-规范形式的指纹
  version: number;          // 生成时的图版本
  stale: boolean;           // 惰性失效标记
  _labels?: unknown;        // 惰性构建的输出
}

/** 创建路径条目，计算规范哈希 */
export function makeEntry(
  rule: { normalize: 'none' | 'reverse' | 'canonical'; output: (nodes: NodeId[]) => unknown },
  nodes: NodeId[],
  graphVersion:D number,
): PathEntry {
  let canonical = nodes;
  if (rule.normalize === 'reverse' && shouldReverse(nodes)) {
    canonical = [...nodes].reverse();
  } else if (rule.normalize === 'canonical') {
    canonical = boothMinimalRotation(nodes);
  }
  const hash = RollingHash.hashSequence(canonical);
  return { nodes, hash, version: graphVersion, stale: false };
}

function shouldReverse(nodes: NodeId[]): boolean {
  // 字典序较小者为代表元
  for (let i = 0, j = nodes.length - 1; i < j; i++, j--) {
    if (nodes[i] < nodes[j]) return false;
    if (nodes[i] > nodes[j]) return true;
  }
  return false;
}
```

## 四、算法层实现

### 4.1 Booth 最小旋转 `ops/booth.ts`

```typescript
/**
 * Booth 算法：返回字符串数组字典序最小旋转的起始下标。
 * O(L) 时间，O(L) 空间。幂等：booth(booth(s)) === booth(s)。
 *
 * 璇玑图原型：同一首回文诗从不同字起读仍是同一首，
 * 取字典序最小旋转作为规范代表元。
 */
export function boothMinimalRotation<T extends string>(arr: readonly T[]): T[] {
  const n = arr.length;
  if (n <= 1) return [...arr];

  const s = [...arr, ...arr];  // 双倍串
  const f = new Int32Array(2 * n).fill(-1);
  let k = 0;

  for (let j = 1; j < 2 * n; j++) {
    let i = f[j - k - 1];
    while (i !== -1 && s[j] !== s[k + i + 1]) {
      if (s[j] < s[k + i + 1]) k = j - i - 1;
      i = f[i];
    }
    if (i === -1 && s[j] !== s[k + i + 1]) {
      if (s[j] < s[k + i + 1]) k = j;
      f[j - k] = -1;
    } else {
      f[j - k] = i + 1;
    }
  }

  return s.slice(k, k + n);
}
```

### 4.2 滚动哈希 `ops/rolling-hash.ts`

```typescript
/**
 * 滚动哈希：前缀/后缀哈希已知时，O(1) 组合出新路径哈希。
 *
 * 璇玑图原型：增量边插入时，前缀哈希 + 新边 + 后缀哈希
 * 直接组合，不需要重新遍历整条路径。
 */
const BASE = 131n;        // 大素数基数
const MOD = 2n ** 64n;    // 64-bit 自然溢出
const POW = [1n];         // 幂次表，惰性扩展

function ensurePow(n: number): void {
  while (POW.length <= n) POW.push((POW[POW.length - 1]! * BASE) % MOD);
}

export class RollingHash {
  /** 单条序列的哈希 */
  static hashSequence(nodes: readonly string[]): string {
    let h = 0n;
    for (const n of nodes) {
      for (let i = 0; i < n.length; i++) {
        h = (h * BASE + BigInt(n.charCodeAt(i))) % MOD;
      }
      h = (h * BASE + 1n) % MOD;  // 分隔符
    }
    return h.toString(16);
  }

  /**
   * O(1) 组合：hash(prefix + [mid] + suffix)
   * 前提：prefixHash 和 suffixHash 已知。
   */
  static combine(
    prefixHash: bigint,
    prefixLen: number,
    mid: string,
    suffixHash: bigint,
    suffixLen: number,
  ): bigint {
    ensurePow(prefixLen + 1);
    let midHash = 0n;
    for (let i = 0; i < mid.length; i++) {
      midHash = (midHash * BASE + BigInt(mid.charCodeAt(i))) % MOD;
    }
    midHash = (midHash * BASE + 1n) % MOD;
    return ((prefixHash * POW[1]! + midHash) * POW[suffixLen]! + suffixHash) % MOD;
  }
}
```

### 4.3 不变量检查器 `ops/invariants.ts`

```typescript
import type { PathIndex } from '../index/path-index.ts';
import type { GraphSpace } from '../core/graph-space.ts';

export interface InvariantResult {
  id: 'I1' | 'I2' | 'I3' | 'I4' | 'I5';
  ok: boolean;
  detail: string;
}

export interface InvariantThresholds {
  thetaStale: number;   // I4: stale/total 上限，默认 0.3
  thetaDepth: number;   // I3: 平均路径长度差上限，默认 3
}

/**
 * 璇玑图原型：方阵的对称性、中心性是保证各种读法成立的全局守护条件。
 * 不变量是启发式触发条件——违反只导致性能退化，不导致错误输出。
 */
export class InvariantChecker {
  private thresholds: InvariantThresholds;

  constructor(thresholds?: Partial<InvariantThresholds>) {
    this.thresholds = {
      thetaStale: thresholds?.thetaStale ?? 0.3,
      thetaDepth: thresholds?.thetaDepth ?? 3,
    };
  }

  /** I4: 失效比例 stale/total ≤ θ_stale —— O(1) 增量计数器 */
  checkI4(index: PathIndex): InvariantResult {
    const { total, stale } = index.counters;
    const ratio = total === 0 ? 0 : stale / total;
    return {
      id: 'I4',
      ok: ratio <= this.thresholds.thetaStale,
      detail: `stale=${stale}, total=${total}, ratio=${ratio.toFixed(3)}, θ=${this.thresholds.thetaStale}`,
    };
  }

  /** I5: 版本一致性 —— 抽样校验 */
  checkI5(index: PathIndex, graph: GraphSpace): InvariantResult {
    const sample = index.sample(100);  // 抽样 100 条
    let violations = 0;
    for (const entry of sample) {
      if (entry.version > graph.version) violations++;
      if (entry.stale) continue;
      // 非 stale 路径的边必须仍存在于图中
      for (let i = 0; i < entry.nodes.length - 1; i++) {
        const out = graph.outEdges(entry.nodes[i]!, new Set());
        if (!out.includes(entry.nodes[i + 1]!)) violations++;
      }
    }
    return { id: 'I5', ok: violations === 0, detail: `${violations} version violations in sample` };
  }

  checkAll(index: PathIndex, graph: GraphSpace): InvariantResult[] {
    return [this.checkI4(index), this.checkI5(index)];
  }
}
```

## 五、索引层与增量引擎

### 5.1 路径索引 `index/path-index.ts`

```typescript
import type { PathEntry, NodeId } from '../core/path-entry.ts';

/**
 * 每个规则维护一套索引。
 *
 * 璇玑图原型：把已经读出的诗（路径）物化存储，下次直接返回。
 * startIndex/endIndex 按起点/终点+长度分桶，加速增量配对。
 */
export class PathIndex {
  /** 按起点+长度分桶 */
  startIndex = new Map<NodeId, Map<number, PathEntry[]>>();
  /** 按终点+长度分桶 */
  endIndex = new Map<NodeId, Map<number, PathEntry[]>>();
  /** 规范哈希去重 */
  hashIndex = new Map<string, PathEntry>();
  /** 删除时定位经过该边的路径 */
  edgeToPaths = new Map<string, Set<string>>();
  /** 增量计数器 */
  counters = { total: 0, stale: 0 };

  add(entry: PathEntry): void {
    if (this.hashIndex.has(entry.hash)) return;
    this.hashIndex.set(entry.hash, entry);
    const len = entry.nodes.length - 1;

    this.pushBucket(this.startIndex, entry.nodes[0]!, len, entry);
    this.pushBucket(this.endIndex, entry.nodes[entry.nodes.length - 1]!, len, entry);

    for (let i = 0; i < entry.nodes.length - 1; i++) {
      const key = `${entry.nodes[i]}->${entry.nodes[i + 1]}`;
      let set = this.edgeToPaths.get(key);
      if (!set) { set = new Set(); this.edgeToPaths.set(key, set); }
      set.add(entry.hash);
    }
    this.counters.total++;
  }

  /** 标记经过某边的所有路径为 stale —— O(k) */
  markStale(edgeKey: string): number {
    const hashes = this.edgeToPaths.get(edgeKey);
    if (!hashes) return 0;
    let count = 0;
    for (const h of hashes) {
      const entry = this.hashIndex.get(h);
      if (entry && !entry.stale) {
        entry.stale = true;
        this.counters.stale++;
        count++;
      }
    }
    return count;
  }

  /** 按起点查询非 stale 条目 */
  queryByStart(start: NodeId): PathEntry[] {
    const buckets = this.startIndex.get(start);
    if (!buckets) return [];
    const result: PathEntry[] = [];
    for (const entries of buckets.values()) {
      for (const e of entries) if (!e.stale) result.push(e);
    }
    return result;
  }

  /** 长度分桶获取——增量配对用 */
  getEndBuckets(node: NodeId): Map<number, PathEntry[]> {
    return this.endIndex.get(node) ?? new Map();
  }
  getStartBuckets(node: NodeId): Map<number, PathEntry[]> {
    return this.startIndex.get(node) ?? new Map();
  }

  sample(n: number): PathEntry[] {
    const all = [...this.hashIndex.values()];
    if (all.length <= n) return all;
    const result: PathEntry[] = [];
    const step = Math.floor(all.length / n);
    for (let i = 0; i < all.length && result.length < n; i += step) result.push(all[i]!);
    return result;
  }

  clear(): void {
    this.startIndex.clear();
    this.endIndex.clear();
    this.hashIndex.clear();
    this.edgeToPaths.clear();
    this.counters = { total: 0, stale: 0 };
  }

  private pushBucket(map: Map<NodeId, Map<number, PathEntry[]>>, node: NodeId, len: number, entry: PathEntry): void {
    let byLen = map.get(node);
    if (!byLen) { byLen = new Map(); map.set(node, byLen); }
    let list = byLen.get(len);
    if (!list) { list = []; byLen.set(len, list); }
    list.push(entry);
  }
}
```

### 5.2 增量引擎 `index/incremental.ts`

```typescript
import type { GraphSpace, XJEdge, NodeId } from '../core/graph-space.ts';
import type { PathRule } from '../core/path-rule.ts';
import type { PathEntry } from '../core/path-entry.ts';
import { makeEntry } from '../core/path-entry.ts';
import { PathIndex } from './path-index.ts';

/**
 * 增量边插入：只处理经过新边的路径。
 *
 * 璇玑图原型：改一字只重读经过该字的诗。
 * 长度分桶后只遍历合法长度组合 preLen+1+sufLen ∈ [lMin, lMax]，
 * 避免全笛卡尔积。
 */
export function onEdgeAdded(
  edge: XJEdge,
  rule: PathRule,
  graph: GraphSpace,
  index: PathIndex,
): PathEntry[] {
  if (!rule.edgeTypes.has(edge.type)) return [];

  const newPaths: PathEntry[] = [];
  const { lMin, lMax } = rule;

  // 前缀：以 edge.source 为终点的已有路径
  const preBuckets = index.getEndBuckets(edge.source);
  // 后缀：以 edge.target 为起点的已有路径
  const sufBuckets = index.getStartBuckets(edge.target);

  // 长度分桶裁剪：只遍历 preLen+1+sufLen ∈ [lMin, lMax] 的组合
  for (const [preLen, prefixes] of preBuckets) {
    for (const [sufLen, suffixes] of sufBuckets) {
      const totalLen = preLen + 1 + sufLen;
      if (totalLen < lMin || totalLen > lMax) continue;

      for (const pre of prefixes) {
        if (pre.stale) continue;
        for (const suf of suffixes) {
          if (suf.stale) continue;

          // 拼接：pre.nodes + [edge.source, edge.target] + suf.nodes
          const nodes: NodeId[] = [
            ...pre.nodes,
            edge.source,
            edge.target,
            ...suf.nodes,
          ];

          // 简单路径检查
          if (rule.simple && hasDuplicate(nodes)) continue;

          // 节点约束检查
          if (rule.nodeConstraint) {
            let ok = true;
            for (const n of nodes) {
              const attrs = graph.getNodeAttrs(n);
              if (!attrs || !rule.nodeConstraint(n, attrs)) { ok = false; break; }
            }
            if (!ok) continue;
          }

          const entry = makeEntry(rule, nodes, graph.version);
          index.add(entry);
          newPaths.push(entry);
        }
      }
    }
  }

  // 也处理仅含新边的单边路径
  if (lMin <= 1 && lMax >= 1) {
    const startAttrs = graph.getNodeAttrs(edge.source);
    if (startAttrs && rule.start(edge.source, startAttrs)) {
      const entry = makeEntry(rule, [edge.source, edge.target], graph.version);
      index.add(entry);
      newPaths.push(entry);
    }
  }

  return newPaths;
}

/**
 * 增量边删除：标记经过该边的路径为 stale。O(k)。
 *
 * 璇玑图原型：删一字只标记经过该字的诗为失效，不重新读全图。
 */
export function onEdgeRemoved(
  edge: XJEdge,
  rule: PathRule,
  index: PathIndex,
): number {
  const key = `${edge.source}->${edge.target}`;
  return index.markStale(key);
}

function hasDuplicate(nodes: NodeId[]): boolean {
  const seen = new Set<NodeId>();
  for (const n of nodes) {
    if (seen.has(n)) return true;
    seen.add(n);
  }
  return false;
}
```

### 5.3 局部重组 `index/rebalance.ts`

```typescript
import type { GraphSpace, NodeId } from '../core/graph-space.ts';
import type { PathRule } from '../core/path-rule.ts';
import { PathIndex } from './path-index.ts';
import { enumerate } from '../query/query-engine.ts';

/**
 * 局部重组（"旋转"）：只影响 1-hop 邻域。
 *
 * 璇玑图原型：类比红黑树旋转的局部性——
 * 不变量违规时只重组受影响区域，不全局重建。
 */
export function rebalance(
  node: NodeId,
  rule: PathRule,
  graph: GraphSpace,
  index: PathIndex,
): void {
  // 1. 收集 1-hop 邻域
  const nbrs = new Set<NodeId>([node]);
  for (const t of graph.outEdges(node, rule.edgeTypes)) nbrs.add(t);
  for (const s of graph.inEdges(node, rule.edgeTypes)) nbrs.add(s);

  // 2. 失效邻域内所有索引条目
  for (const n of nbrs) {
    for (const entry of index.queryByStart(n)) {
      if (entry.nodes.some(v => nbrs.has(v))) {
        entry.stale = true;
        index.counters.stale++;
      }
    }
  }

  // 3. 在邻域内重新枚举
  for (const start of nbrs) {
    const attrs = graph.getNodeAttrs(start);
    if (!attrs || !rule.start(start, attrs)) continue;
    enumerate(graph, rule, [start], index);
  }
}
```

### 6.1 查询引擎 `query/query-engine.ts`

```typescript
import type { GraphSpace, NodeId } from '../core/graph-space.ts';
import type { PathRule } from '../core/path-rule.ts';
import type { PathEntry } from '../core/path-entry.ts';
import { makeEntry } from '../core/path-entry.ts';
import { PathIndex } from '../index/path-index.ts';

/**
 * 静态全量枚举：DFS + 约束剪枝。
 *
 * 璇玑图原型：顺读——从每个起点出发，按规则遍历所有合法路径。
 * 复杂度：最坏 O(b^lMax)，输出敏感 O(|O_R|·L)。
 */
export function enumerate(
  graph: GraphSpace,
  rule: PathRule,
  starts: NodeId[],
  index: PathIndex,
): PathEntry[] {
  const result: PathEntry[] = [];
  const seen = new Set<string>();

  for (const start of starts) {
    const attrs = graph.getNodeAttrs(start);
    if (!attrs || !rule.start(start, attrs)) continue;
    dfs(graph, rule, index, start, [start], 0, result, seen);
  }
  return result;
}

function dfs(
  graph: GraphSpace,
  rule: PathRule,
  index: PathIndex,
  node: NodeId,
  path: NodeId[],
  depth: number,
  result: PathEntry[],
  seen: Set<string>,
): void {
  // 达到最小长度，尝试输出
  if (depth >= rule.lMin) {
    const entry = makeEntry(rule, path, graph.version);
    if (!seen.has(entry.hash)) {
      seen.add(entry.hash);
      index.add(entry);
      result.push(entry);
    }
  }

  // 达到最大长度，停止
  if (depth >= rule.lMax) return;

  // 遍历合法出边
  const neighbors = graph.outEdges(node, rule.edgeTypes);
  for (const next of neighbors) {
    // 简单路径检查
    if (rule.simple && path.includes(next)) continue;
    // 节点约束
    if (rule.nodeConstraint) {
      const attrs = graph.getNodeAttrs(next);
      if (!attrs || !rule.nodeConstraint(next, attrs)) continue;
    }
    dfs(graph, rule, index, next, [...path, next], depth + 1, result, seen);
  }
}

/**
 * 查询 + 回退契约。
 *
 * 璇玑图原型：先查物化索引（已经读出的诗），未命中则回退全量枚举。
 * 永不返回 stale 条目。
 */
export function query(
  rule: PathRule,
  start: NodeId,
  index: PathIndex,
  graph: GraphSpace,
  fallback?: () => PathEntry[],
): PathEntry[] | null {
  const entries = index.queryByStart(start);
  const live = entries.filter(e => !e.stale);

  if (live.length === 0) {
    // 回退：调用方提供的全量枚举或宿主查询
    return fallback ? fallback() : null;
  }

  // stale 比例检查
  const total = entries.length;
  const staleCount = total - live.length;
  if (total > 0 && staleCount / total > 0.3) {
    return fallback ? fallback() : null;
  }

  return live;
}
```

### 7.1 适配器 `src/xuanji/XuanjiAdapter.ts`

```typescript
import { GraphSpace, PathRule, PathIndex, onEdgeAdded, onEdgeRemoved, query, enumerate } from '@xuanji/core';
import type { GraphData, GraphNode, GraphEdge, GraphDelta } from '../types/index.ts';

/**
 * 宿主适配层：把项目的 GraphData 转换为 xuanji.GraphSpace，
 * 把项目的分析需求转换为 xuanji.PathRule，然后委托 xuanji 执行。
 *
 * 这是唯一与宿主耦合的模块——璇玑图规范的 §九 模块契约。
 */
export class XuanjiAdapter {
  private space = new GraphSpace();
  private indexes = new Map<string, PathIndex>();  // ruleName → PathIndex

  /** 从项目的 GraphData 构建图空间 */
  loadGraph(data: GraphData): void {
    this.space = new GraphSpace();
    for (const n of data.nodes) {
      this.space.addNode(n.id, {
        label: n.label,
        role: n.type,
        tags: n.tags,
        type: n.type,
        filePath: n.filePath,
        isExported: n.properties?.isExported,
      });
    }
    for (const e of data.edges) {
      this.space.addEdge({ id: e.id, source: e.source, target: e.target, type: e.type, weight: e.weight });
    }
    // 图重建后所有索引失效
    for (const idx of this.indexes.values()) idx.clear();
  }

  /** 增量应用 GraphDelta */
  applyDelta(delta: GraphDelta): void {
    for (const e of delta.removedEdges) {
      this.space.removeEdge({ id: e.id, source: e.source, target: e.target, type: e.type });
      for (const [name, idx] of this.indexes) {
        const rule = RULES.get(name);
        if (rule) onEdgeRemoved({ id: e.id, source: e.source, target: e.target, type: e.type }, rule, idx);
      }
    }
    for (const e of delta.addedEdges) {
      this.space.addEdge({ id: e.id, source: e.source, target: e.target, type: e.type });
      for (const [name, idx] of this.indexes) {
        const rule = RULES.get(name);
        if (rule) onEdgeAdded({ id: e.id, source: e.source, target: e.target, type: e.type }, rule, this.space, idx);
      }
    }
  }

  /** 查询环 */
  queryCycles(): string[][] {
    const rule = RULES.get('cycles')!;
    const idx = this.getOrCreateIndex('cycles');
    if (idx.counters.total === 0) enumerate(this.space, rule, this.allStarts(rule), idx);
    const entries = query(rule, '', idx, this.space, () => enumerate(this.space, rule, this.allStarts(rule), idx));
    return (entries ?? []).map(e => e.nodes);
  }

  /** 查询死代码（从入口不可达的节点） */
  queryDeadCode(): string[] {
    const rule = RULES.get('reachable')!;
    const idx = this.getOrCreateIndex('reachable');
    if (idx.counters.total === 0) enumerate(this.space, rule, this.entryStarts(rule), idx);
    // 可达节点
    const reachable = new Set<string>();
    for (const e of idx.hashIndex.values()) {
      if (!e.stale) for (const n of e.nodes) reachable.add(n);
    }
    // 不可达 = 全部 - 可达
    const dead: string[] = [];
    for (const node of this.allNodes()) {
      if (!reachable.has(node)) dead.push(node);
    }
    return dead;
  }

  /** 查询影响传播 */
  queryImpact(nodeId: string, maxDepth: number): Map<string, number> {
    const rule = RULES.get('impact')!;
    const idx = this.getOrCreateIndex('impact');
    if (idx.counters.total === 0) enumerate(this.space, rule, [nodeId], idx);
    const result = new Map<string, number>();
    for (const e of query(rule, nodeId, idx, this.space) ?? []) {
      if (!e.stale) for (let i = 0; i < e.nodes.length; i++) {
        const depth = i;
        if (depth > 0 && depth <= maxDepth) {
          const prev = result.get(e.nodes[i]!) ?? Infinity;
          result.set(e.nodes[i]!, Math.min(prev, depth));
        }
      }
    }
    return result;
  }

  /** 查询最短路 */
  queryShortestPath(source: string, target: string): string[] | null {
    const rule = RULES.get('shortest')!;
    const idx = this.getOrCreateIndex('shortest');
    if (idx.counters.total === 0) enumerate(this.space, rule, [source], idx);
    const entries = query(rule, source, idx, this.space);
    if (!entries) return null;
    let best: string[] | null = null;
    for (const e of entries) {
      if (e.nodes[e.nodes.length - 1] === target) {
        if (!best || e.nodes.length < best.length) best = e.nodes;
      }
    }
    return best;
  }

  private getOrCreateIndex(name: string): PathIndex {
    let idx = this.indexes.get(name);
    if (!idx) { idx = new PathIndex(); this.indexes.set(name, idx); }
    return idx;
  }

  private allStarts(rule: PathRule): string[] {
    const result: string[] = [];
    for (const node of this.allNodes()) {
      const attrs = this.space.getNodeAttrs(node);
      if (attrs && rule.start(node, attrs)) result.push(node);
    }
    return result;
  }

  private entryStarts(rule: PathRule): string[] { return this.allStarts(rule); }

  private *allNodes():
 Iterable<string> {
    yield* this.space.nodeIds();
  }
}
```

| 维度 | 不造轮子方案（前一文档） | 造轮子方案（本文档） |
|------|----------------------|-------------------|
| **实现位置** | 改造既有 .ts 文件 | 独立 packages/xuanji/ + 适配层 |
| **Booth 算法** | 加在 CycleDFS.ts | ops/booth.ts 独立模块 |
| **增量引擎** | 改造分析器方法签名 | index/incremental.ts 独立模块 |
| **路径索引** | 不引入全套 | index/path-index.ts 全套实现 |
| **不变量** | 复用 changeRatio | ops/invariants.ts I1-I5 全实现 |
| **NFA** | 不引入 | core/nfa.ts 可选实现 |
| **规则组合** | 改造 RuleEngine 内部 | core/path-rule.ts ∪∩·* 代数 |
| **可复用性** | 仅限本项目 | 可独立发布为 npm 包 |
| **迁移风险** | 低（改既有代码） | 中（新增依赖 + 适配层） |
| **迁移工作量** | ~8d | ~15d（含库开发） |
| **长期收益** | 项目内优化 | 跨项目复用 + 项目内优化 |

### 选择建议

- **如果优化仅限本项目**：用"不造轮子"方案，工作量小、风险低。
- **如果璇玑图范式可复用于其他图项目**（如 ANIC 工作流图、知识图谱）：造轮子，一次投入多次复用。
- **混合路径**：先落"不造轮子"方案的 P0—P1（Booth + 多重边 + 缓存增量 + 规则共享），再渐进抽取为独立库——先在项目内验证算法正确性，再提取为 `packages/xuanji/`，避免库 API 在没有真实调用方的情况下空转设计。

### 12.2 设计稿中需要修正的三处

1. **增量插入的拼接公式与完备性**。设计稿写
   `nodes = pre.nodes + [u,v] + suf.nodes`：`pre.nodes` 已以 `u` 结尾、
   `suf.nodes` 已以 `v` 开头，再插入 `[u,v]` 会重复两个节点。正确拼接是
   `pre.nodes.concat(suf.nodes)`（零长度前缀 `[u]` / 后缀 `[v]` 虚拟补充）。
   更重要的是**桶配对本身不完备**：索引只存 `len ≥ lMin` 的完整合法路径，
   因此 `lMin ≥ 2` 时短前缀/后缀不在桶里，`closed` 规则的非闭合前缀更不合法。
   实现改为「旧图反向 DFS 前缀 × 新图正向 DFS 后缀 + `isLegalPath` 终判」，
   复杂度 `O(前缀走法 × 后缀走法)`，以 `INCREMENTAL_WORK_BUDGET`（默认 50 000，
   超限 `index.clear()` 降级）兜底。
2. **闭合路径的规范化**。闭合路径以 `[v0,…,vk]` 且 `vk=v0` 表示；直接对整串做
   Booth 旋转会得到 `[v1,…,vk,v0]` 这类非法表示，且同一环不同起点仍会产生不同哈希。
   `canonicalNodes` 对 `closed` 规则只旋转 `nodes.slice(0,-1)`。
3. **滚动哈希的组合公式**。设计稿的 `combine` 用 `POW[1]` 且需要分别传
   `prefixLen/suffixLen`、还要单独计算 mid 哈希；实现改为「(hash, 字符长度) 对」
   的幺半群，`concat(a,b) = a.hash·B^b.len + b.hash`，无需外部传长度，也不会把
   幂次写错。
