# 长期愿景评估（六维基线与趋势）

> 建立时间：cycle-103（2026-10-19）。本文件是测试体系 KPI「长期愿景六维评分趋势」的
> 定义文件与数据源。**评分口径**：每循环收口时由当轮评估报告给出各维现值（0-10，
> 一位小数），本文件只记录与环比；历史轮次在定义文件存在前没有评分，**不伪造**——
> 趋势表从 cycle-103 起记录。
>
> **六维的取法**（映射决策，记录在案）：上游框架 `docs/评估评审研究开发体系.md` §二
> 列了七维（功能与业务/架构与设计/代码与工程/前端与体验/测试体系/非功能与运维/评审与验收）。
> KPI 所称「六维」取前六维作为**产品本体**维度；第七维「评审与验收」是过程性维度，
> 已由 G0-G3 门禁台账独立度量（gate ledger），不重复计入评分——避免同一证据源双记。
> 若未来要并回七维，本表加列即可，历史数据不受影响。

## 4. 评分纪律

1. 每循环收口时评分，数据必须来自当轮可核查证据（评估报告/测试报告/门禁台账）。
2. 单调不减是设计目标不是硬约束：真实下降如实记，隐瞒或无据改分视为审计事件。
3. 维度定义变更（如并回七维）须在本文件留版本注记。
