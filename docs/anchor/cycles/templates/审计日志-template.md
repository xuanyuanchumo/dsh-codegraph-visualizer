## 2. H1–H4 检查点自动评估记录

> L4 规则：每个触发的检查点由 AI 自动执行「触发 → 评估 → 记录」三步；仅当触发熔断条件（§3.4 熔断条件列）时回退 L3 请求人工。

| 检查点 | 是否触发 | 触发事项                                  | 自动评估内容                           | 评估结论（通过/熔断） | 审计证据（命令/报告路径） |
| ------ | -------- | ----------------------------------------- | -------------------------------------- | --------------------- | ------------------------- |
| H1     | 是/否    | （安全敏感操作描述，如无则填「无」）      | 是否涉及真实用户数据/明文凭据/隔离方案 |                       |                           |
| H2     | 是/否    | （破坏性操作描述，如无则填「无」）        | 影响范围分析 + 回滚方案                |                       |                           |
| H3     | 是/否    | （Release 交付闸，最终循环必触发）        | 门禁全绿 + 性能未退 >5% + 审计完整     |                       |                           |
| H4     | 是/否    | （门禁判定存疑/例外申请，如无则填「无」） | 判定依据复核（命令/报告/证据）         |                       |                           |
