## DSH web 集成修复

### 1. Client bundle 格式
- **问题**: DSH web 用经典 `<script>` 标签加载 bundle，不支持 ESM `import`
- **修复**: 改用 CJS 格式 + `window.__ModuleLoader__.load({id, factory: (require) => {...}})` 包装
- **参考**: dsh-better-sidebar 的 lib/client.js

### 2. 依赖内联
- **问题**: `require("zustand")` 不在 DSH module table 中
- **修复**: zustand/cytoscape/cytoscape-dagre 从 dependencies 移到 devDependencies（内联到 bundle）
- react-dom 移到 peerDependencies（DSH web 提供）

### 3. Slots API
- **问题**: `ctx.slots.register('shell.overlay', {...})` 调用格式不匹配
- **修复**: 改用 `ctx.slots.inject('settings.section', () => ctx.slots.register({name, id, ...}, Component))`

### 4. 可选服务访问
- **问题**: `ctx.betterSidebar` 访问需要 inject 声明
- **修复**: 用 `try-catch` + `(ctx as unknown as Record<string, unknown>).betterSidebar` 安全访问
