## 二、图谱按需加载方案逐条对齐分析

### 2.1 核心原则对齐

| 原则 | 方案要求 | 代码实现 | 对齐状态 |
|------|----------|----------|----------|
| 1. 加载粒度是节点路径 | 按节点逐级加载 | `loadNodeChildren(nodeId)` 按节点加载子级 | ✅ 对齐 |
| 2. L0-L3只是语义分类 | 不作为批量加载单位 | 聚类深度 `clusterDepth` 控制显示粒度，非加载批次 | ✅ 对齐 |
| 3. 首屏只请求bootstrap | 根节点+顶层第一页+URL路径恢复 | `loadBootstrap()` → `fetchBootstrap()` → 50个顶层节点 | ✅ 对齐 |
| 4. 用户操作才加载子级 | 点击节点才加载直接子级 | `expandNode()` → `loadNodeChildren()` | ✅ 对齐 |
| 5. 不因层级全量加载 | 绝不加载同层全部 | 每次只加载 `parentId === nodeId` 的子节点 | ✅ 对齐 |
| 6. 跨文件边先聚合 | 先文件级聚合，后按节点细化 | 聚类后 `aggregateEdges()` 边聚合 | ✅ 对齐 |
| 7. 一次最多两个函数 | 展开预算，非数据截断 | `FUNCTION_BODY.MAX_EXPANDED = 2` + `enforceFunctionBodyBudget()` | ✅ 对齐 |
| 8. 索引不阻塞首屏 | 未就绪先展示L0骨架 | bootstrap返回 `indexStatus`，但无数据时回退全量拉取 | ⚠️ 部分对齐 |
| 9. 三层独立加载 | 结构/行为/运行时独立 | 有视图模式切换但无严格三层隔离面板 | ⚠️ 部分对齐 |
| 10. 活跃渲染≤1500 | 动态聚类800/1200/1500 | `DYNAMIC_CLUSTER` + `getDynamicMaxVisibleNodes()` | ✅ 对齐 |
