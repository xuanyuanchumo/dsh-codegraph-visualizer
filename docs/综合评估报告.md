## 三、关键BUG详细分析

### BUG-1: NodeDetail面板不出现 (P0)

**现象**: 单击任何节点(聚类节点或非聚类节点)后, Cytoscape中节点被正确选中(`cy.nodes(':selected')`返回节点), 但NodeDetail面板不出现。

**代码路径**:
```
InteractionController.cy.on('tap', 'node') 
  → onNodeTap(nodeId) 
  → handleNodeTap(id) 
  → setSelectedNode(id) + getDataRef.current?.getSelectedNodeData() 
  → DataController.getSelectedNodeData() 
  → this.currentNodes.get(id) → null ← 问题在这里
```

**根因**: `DataController.currentNodes` Map 中没有对应的节点数据。虽然 `updateData()` 方法中有 `this.currentNodes.set(n.id, n)` 的逻辑, 但 `currentNodes` 可能因为以下原因不包含节点:
1. `updateData()` 的增量更新逻辑在某些条件下跳过了 `currentNodes.set()` 
2. `currentNodes` 在某些代码路径中被 `clear()` 后没有重新填充
3. `getDataRef.current` 可能为null(ref未正确设置)

**修复建议**: 
- 在 `getSelectedNodeData()` 中增加fallback: 如果 `currentNodes.get(id)` 返回null, 从Cytoscape节点数据中构造GraphNode
- 添加调试日志: 在 `getSelectedNodeData()` 中输出 `currentNodes.size` 和 `id`, 确认Map是否为空

### BUG-2: 聚类节点双击展开不工作 (P0)

**现象**: 双击聚类节点后, 聚类没有展开, 节点数量不变。

**代码路径**:
```
InteractionController.cy.on('dbltap', 'node')
  → onNodeDoubleTap(nodeId)
  → handleNodeDoubleTap(nodeId)
  → handleNodeDoubleTapRef.current(nodeId)
  → getDataRef.current?.getNodeData(nodeId) → null ← 问题在这里
  → if (!data) return ← 提前返回, 不执行expandNode
```

**根因**: 与BUG-1相同, `getNodeData()` 从 `currentNodes` Map 中查找聚类节点返回null。

**修复建议**: 
- 在 `handleNodeDoubleTapRef.current` 中, 对聚类节点使用Cytoscape节点数据(`cy.getElementById(nodeId).data()`)来判断 `isCluster`, 而不依赖 `getNodeData()`
- 或者修复 `currentNodes` Map 使其包含聚类节点

## 六、总结

DSH CodeGraph Visualizer v0.2.0 在功能完整性、界面现代化、主题适配、图谱视图等方面表现良好(8.0+评分), 但存在2个P0级BUG(节点详情面板不出现、聚类展开不工作)严重影响核心用户体验。这两个BUG的根因相同: `DataController.currentNodes` Map 中缺少节点数据, 导致 `getSelectedNodeData()` 和 `getNodeData()` 返回null。

架构层面存在3个核心技术债务(setViewMode状态机、IRenderer胖接口、适配器缺乏统一抽象), 建议在下一个迭代中优先处理。

测试体系需要加强组件测试(25%→80%+)和Hooks测试(0%→90%+), 并启用被skip的J4/J5 E2E测试。
