## 一、体系定位与硬约束

本插件不是孤立项目，而是依托 DSH 的插件项目，必须放在 DSH 宿主、DSH UI 插件、浏览器与真实用户旅程中评审。

核心约束：

1. **DSH 事实基线**：DSH 是 DeepSeek AI 开源的 agent harness，采用 **everything-is-a-plugin** 架构，基于 Cordis；当前为 developer preview，快速迭代，**会有兼容性破坏性变更**。
2. **运行与开发基线**：支持 `npx @deepseek-ai/dsh web`，默认 `http://127.0.0.1:3080`；源码方式为 `pnpm install`、`pnpm run build`、`pnpm dsh web`；`pnpm run dev:web` 支持 Web 重建；`make help` 列出 Web/Desktop 目标。
3. **规范入口**：开发指南、架构文档、`AGENTS.md` 是开发入口；`CONTRIBUTING.md`、`SAFETY.md`、`BENCHMARK.md`、`BRAND_GUIDELINES.md` 分别约束贡献、安全、基准与品牌。
4. **插件发现**：插件仓库应添加 `dsh-plugin` topic。
5. **版本事实**：README 表格出现 `release(dsh): 0.1.7-rc.2`，但必须以本项目 `package.json`、`pnpm-lock.yaml` 实际锁定版本为准（仓库中不存在 `vendor/`、`patches/`、`snapshots/` 目录）。
6. **工程事实**（本次核对）：仓库顶层目录为 `src`、`tests`、`docs`、`scripts`、`.github`（另有 `coverage`、`dist`、`screenshots`、`test-results` 等构建/测试产物目录）；不存在 `apps`、`packages`、`native`、`python`、`vendor`、`website`、`snapshots`。测试侧只有一个 Vitest 配置 `vitest.config.ts`（`vitest.e2e.config.ts`、`vitest.web.config.ts`、`vitest.snapshot.config.ts`、`vitest.web.perf.config.ts`、`vitest.web-stress.config.ts`、`vitest.bench.config.ts` 均不存在）；E2E 由 `playwright.config.ts` 定义。工程侧为 `tsconfig`（host/client/test）、`tsdown`、`oxlint` 与 CI 配置 `.github/workflows/ci.yml`；`lefthook`、`jscpd` 未引入。
7. **不孤立验证**：用户旅程必须在 DSH 内、DSH UI 插件内、标签页兼容场景内、Edge/Chrome 内验证，不能只验证独立页面。

## 三、功能逻辑增强与代码图谱/AST 内核

### 1. 数据对象与结构

| 对象 | 数据结构 | 用途 |
|---|---|---|
| AST | 树、CST、符号表、作用域链 | 解析语法、符号、引用、类型 |
| 代码图谱 | 属性图、邻接表、逆邻接表、CSR | 文件、模块、类、函数、变量、依赖 |
| 调用图 | 有向图、DAG | 调用链、影响分析 |
| 继承/实现图 | 有向图、拓扑结构 | 面向对象关系 |
| 模块依赖图 | 有向图、SCC | 循环依赖、分层 |
| 组件树 | 树、虚拟树 | UI 组件与渲染对齐 |
| 状态图 | 有向图、状态机 | 交互流程、命令、撤销/重做 |
| 视口索引 | 四叉树、R 树、空间哈希 | 大图按需加载、命中测试 |

### 2. 关键算法

- 遍历：DFS、BFS、拓扑排序。
- 强连通：Tarjan/Kosaraju，识别循环依赖。
- 中心性：度中心性、介数中心性、PageRank，识别关键节点。
- 社区发现：用于宏观聚类与着色。
- 路径：最短路径、影响路径、调用链。
- 增量：AST diff、图 diff、哈希/Merkle、缓存失效。
- 布局：力导向、Sugiyama 分层、树布局、正交布局、径向布局、约束布局。
- 大图优化：Barnes-Hut、四叉树、视口裁剪、LOD、边捆绑、标签避让。
- 按需加载：分片、懒加载、预取、取消、LRU 缓存、骨架占位。

### 3. 功能增强点

- 图谱构建：从 AST 到代码图谱，从代码图谱到业务图谱。
- 查询：按符号、文件、依赖、复杂度、风险、变更。
- 过滤：类型、层级、语言、目录、时间、作者、测试覆盖。
- 聚焦：焦点+上下文、邻居展开、路径高亮、社区折叠。
- 对比：版本 diff、分支 diff、AST diff、视觉 diff。
- 时间旅行：历史快照、回放、增量重建。
- 导出与共享：图、视图状态、报告、链接。
- 插件协作：命令面板、快捷键、事件总线、跨插件消息。
- 可访问性：键盘导航、屏幕阅读、对比度、焦点管理。

## 四、可视化图谱：宏观与微观视图

| 视图 | 布局 | 交互 | 视觉呈现 | 测试重点 |
|---|---|---|---|---|
| 宏观图谱 | 社区聚类、力导向、分层、径向 | 缩放、平移、框选、聚合、钻取 | 聚类色、边捆绑、节点大小、密度热力 | 大图性能、按需加载、标签避让 |
| 微观图谱 | 树、正交、分层、局部力导向 | 悬停、点击、双击、右键、拖拽 | 节点详情、边语义、路径动画、diff 色 | 选择状态、检查器、键盘、视觉回归 |
| AST 视图 | 树、折叠树、缩进树 | 展开、折叠、搜索、定位 | 语法层级、类型色、错误态 | 解析正确、节点映射、滚动同步 |
| 组件视图 | 组件树、栅格、面板 | 标签页、侧边栏、分栏 | 对齐、间距、层级、响应式 | 组件测试、标签页兼容、主题 |
| 对比视图 | 并排、叠加、差异树 | 同步滚动、差异跳转 | 增删改色、风险热力 | 视觉 diff、状态同步 |

### 渲染与排版要求

- 栅格与间距统一，面板、工具栏、图例、检查器、状态栏对齐。
- 字体、颜色、暗色模式、对比度、焦点态、悬停态、选中态、禁用态一致。
- 节点大小、边宽、标签、图例语义一致。
- 加载态、空态、错误态、降级态完整。
- 动画服务理解，不阻塞操作；支持减少动态效果。
- 响应式：窄屏、分栏、标签页、侧边栏、全屏。
- 国际化：文案、数字、日期、方向。
- 可访问性：键盘、ARIA、屏幕阅读、对比度、焦点顺序。

### 交互逻辑

- 选择、悬停、点击、双击、右键、拖拽、框选、缩放、平移。
- 面包屑、钻取、返回、同步、撤销/重做。
- 命令面板、快捷键、搜索、过滤、布局切换。
- 按需加载：先骨架，再局部，再预取；可取消、可恢复。
- 功能业务与界面渲染对齐：单一状态源，选择器驱动渲染，事件驱动命令，测试覆盖映射。
