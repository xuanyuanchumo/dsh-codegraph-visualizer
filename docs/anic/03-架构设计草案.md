## 1. 总体形态：通用 DSH 插件（包名 `dsh-anic`）

```
dsh-anic/                            # 独立仓库，独立发布
├── package.json                     # dsh.manifestVersion 1; 无 dsh* peerDeps（兼容门必过）
├── cordis.patch.yml                 # bundle 行 id=anic（显式 config 见 §2.4）
├── locale/en.json zh.json           # {meta:{title,description}}，en 为锚
├── assets/icon.svg                  # ≤256KiB
├── src/                             # Host（ESM，node>=22.19 只是宿主要求，非项目假设）
│   ├── index.ts                     # apply(): inject + effect 注册 + disposer
│   ├── runtime/                     # 状态机/账本/熔断（§3）
│   ├── evolve/                      # 信任模型+过程补丁+安全带（§5，本插件核心增量）
│   ├── init/                        # 多栈探测向导（§4）
│   ├── tools/                       # ctx.tools 流程工具面（§7）
│   ├── routes/                      # ctx.webServer HTTP 面（§8）
│   ├── llm/                         # LLM 评审引擎+启发式回落（§6，条件模块）
│   └── shared/                      # dshGeneration 兼容层移植、Logger、i18n keys
├── client/                          # exports["./client"] 唯一客户端入口
│   ├── tabs/anicTab.tsx             # conversation.view 顶部标签
│   ├── graph/                       # workflow-graph 渲染（Cytoscape 模式）
│   ├── approval/                    # 审批卡
│   ├── evolve/                      # 信任曲线/补丁生命周期/撤销窗口 UI（F14）
│   └── store/                       # Zustand + persist
└── mcp/                             # 过渡期 MCP server（M3 后退役为兼容垫片）
```

**通用性铁律（X6/N9）**：代码路径零项目假设——项目相关的一切只存在于目标工作区的 `.cycles/`（数据）与用户配置（命令/维度/权重）。本仓库 dsh-codegraph-visualizer 仅是验证场，深链（F13）是 only-ON 可选增强。

## 2. 宿主集成（有本仓库先例的模式，全部可迁移）

- `inject = ['tools','webServer','sessions']`（src/index.ts:30 同构；workspaceRegistry gen2-only 走 `ctx.get` 探测）；
- 工具/路由/事件注册全在 `ctx.effect` 内收集 disposer（防御式 `typeof d === 'function'` 检查后调用）；
- **SlotRegistry.register 保持原型方法**（兼容矩阵 §7 CRITICAL）；
- `ctx.get(name)` 探测一律 `(key, false)` + 调用点决策（同步 apply() 内严格 get 会杀 loading 中的服务）；
- 事件：`ctx.emit('dsh-anic/gate.arrived|gate.passed|gate.rejected|cycle.started|cycle.finished|breaker.tripped|autonomy.changed|patch.applied|patch.reverted|trust.changed')`。

### 3.x 数据流（门禁一次通过全链路）

```
工具调用 eval-run/gate-check → StateMachine.checkStrict() 判定门到达
  → GateBroker.assembleEvidence(gate) → emit gate.arrived
  → [通道A 审批卡] ─┐
  → [通道B CLI/MCP] ┴→ Ledger.append(hashChain)
  → StateMachine.advance(record)          # 账本记录是唯一推进凭据
  → TrustModel.observe(gateOutcome)       # §5.2 信任事件
  → emit gate.passed/rejected（不拉起下游）
```

## 5. 信任模型与进化引擎（本插件核心增量，对应 F16-F22 / X8-X10）

### 5.1 进化宪法（硬约束，插件核心代码，不在任何可变面上）

1. 人类门只可增不可减、角色只可升权（X8）——PatchEngine 资格检查第一关；
2. 熔断条件/HITL/**账本格式**不可被补丁触碰（X9）；
3. 进化只改流程（图形状/阈值/维度权重/自主级带），永不触碰代码工件（X10）；
4. L4 的进入/离开永远需要人类显式授权（F17 宪法条款）；
5. 一切进化动作进同一账本（F20，审计即真理）；
6. **永不自动销毁工件**（08 §7 宪法条款 6）：归档只移动不删除；`anic_prune` 默认 dry-run；真相源（`gates/ledger*`、`head.json`、`index.jsonl`、`archive/index.jsonl`）永不删除；unmanaged（白名单外）文件永不触碰；
7. **账本记录形状只在 M2 定死一次**（08 §3.2）：它是唯一"事后修改即破坏全部已写链"的数据结构——与条款 2 同源，故定为宪法级。

### 5.2 TrustModel（修 P-1 信任分死端）

```ts
interface TrustState {
  version: 1;
  overall: number;                       // 0-100
  byRole: Record<GateRole, number>;      // 按门角色分桶
  streak: { pass: number; fail: number };// 滞回计数
  frozen: string[];                      // 冻结名单（F22）
}
```

- **种子**：multi-agent-gate trustScore（兼容 ≥70% 语义）；无历史的新项目 = 中性 50；
- **事件**：门高质量通过 +Δ、评审驳回/返工 −Δ、熔断 −−Δ、auto-fix 无改善 −Δ；Δ 由补丁可调（在安全带内）；
- **滞回**：连续 N 次同向事件才生效（默认 N=3），防单次抖动；
- **非对称**：降分系数 > 升分系数（错误成本 > 机会成本——沿用本仓库"宁多 200 不误 304"偏置哲学）；
- 持久化：`.cycles/trust-state.json`（version 1，N10）。

### 5.3 AutonomyGovernor（修 P-4 自主级静态）

- **授权带**：用户初始授予 [floor, ceiling]（如 [L1, L3]；L4 永远在带外，进入必须人类显式授权——宪法 4）；
- 信任分映射带内自主级（映射表可配置）；升降条件 = 滞回通过 + 非熔断状态；
- **每次变更**：写账本（原因+证据）+ UI 显式说明 + 30 分钟一键撤销窗口（revertWindowMinutes）；撤销本身也进账本；
- **优先级**：8 熔断 > 撤销窗口 > 信任升降 > 静态 config（熔断永远即时降级，不被信任分阻拦）。

### 5.4 PatchEngine（修 P-2/P-3：band-history 消费端 + 复盘回流）

```
来源: retrospectives/ tech-debt/ band-detector 漂移 / 评审驳回模式 / 人类提案
  → PatchProposal { id, hypothesis, change, metricsPlan, expiry }
      change ∈ { graph(改 workflow-graph.yaml，过宪法检查), thresholds(改 G 门阈值),
                 dimensionWeights(改评估权重), autonomyBand(仅收紧；放宽必须人类门) }
  → 资格检查（宪法 1-3）──不过→ 拒绝并留痕
  → 安全带判定 ──带内→ 自动应用（L4 事后审计）／带外→ 对应人类门（如 graph 变更走 spec_approve）
  → 应用 = 原子写工件 + Ledger.append({type:'patch.applied', patchId, before/after hash})
  → 度量期（metricsPlan 对比前/后 cycle 指标）
  → 判定: keep（转正，expiry 撤销）| auto-revert（先写 revert 记录再恢复 before 工件，崩溃可续——N4）
  → 防抖: 同参数 30 天内 2 次 revert → 冻结名单，需人类解冻（F22）
```

- **band-history 接入**（修 P-2）：band-detector 规则移植后，漂移信号成为 PatchProposal 的一等来源（性能持续恶化 → 提案收紧性能阈值/触发降级建议）；
- **复盘回流**（修 P-3）：retrospectives 的结构化字段（问题/根因/建议）→ 半自动转为补丁提案（LLM 可用时由模型起草 hypothesis，人工确认）；
- **跨项目复用**（F21）：补丁导出为匿名模板（剥项目数据），存本地模板目录，init 向导可选。
