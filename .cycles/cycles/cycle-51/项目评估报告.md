## DSH 官方规范关键发现

通过 context7 MCP 研究获得：

1. **插件入口**：Function/Constructor/Object 三种形式，通过 `apply(ctx, config)` 注册
2. **生命周期**：`ctx.effect()` 返回 disposer，自动清理，反向注册顺序
3. **依赖注入**：`inject` 声明所需服务，`provide` 声明提供的服务
4. **侧边栏标签页**：`ctx.sidebarRightTabs.register()` + `ctx.slots.inject('sidebar.right.pane.tab', ...)`
5. **标签页类型**：`kind`（类型判别器）、`patterns`（资源匹配）、`priority`（extension/builtin/fallback）
6. **HostConnectionRpc/Fetch**：RPC 通道和 Fetch 路由注册
7. **Desktop 支持**：DSH 有完整 Desktop 支持（Electron），Desktop 也使用 Web 插件 UI
8. **ClientModuleRegistry**：管理客户端模块的加载和重建
