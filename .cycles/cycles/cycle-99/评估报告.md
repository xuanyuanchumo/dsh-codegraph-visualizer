## 2. 迁移过程中发现并修复的问题

### 2.1 P1-SCRIPT-PATHS：三个脚本硬编码嵌套布局

`start-dsh-test.mjs`（REPO_ROOT=join(PLUGIN_ROOT,'..')）、`generate-snapshot.mjs`（ROOT=../..）、`j0-probe.mjs`（@playwright/test 借父工程）全部假定插件嵌在父仓库内。
**修复**：统一 `WORKSPACE = resolveWorkspace()` 解析规则（参数 > 环境变量 > 同级默认），三个脚本各自适配（快照「产出写本仓库、数据源取验证场地」；j0-probe 三级 TOOLCHAIN_ROOTS 解析）。

### 2.2 P1-J0-PROBE-FLAKY：J0 探针两项实测假失败源（本轮最高价值发现）

连续三次 4/8 FAIL（J0-1/1b/2/4），而 Chrome DevTools MCP 手查同一页面 ANIC 标签明明存在。逐层排查后锁定**两个独立缺陷**：

**缺陷 A——残留 kill-switch**：上一轮探针在 J0-6「写入开关 → reload」之后、恢复之前被中途终止（输出管道被 `Select-Object -First 6` 截断杀进程），`localStorage['anic-workflow-tab']='off'` 残留。此后 ANIC 标签永不挂载，J0-1/1b/2/4 全部假失败，且 **FAIL 文本完全看不出是开关问题**（教训：可破坏状态 + 可中断探针 = 必须自愈入口）。
**修复**：探针启动时检测残留开关并移除+刷新（--keep-switch 模式除外）。

**缺陷 B——全新 profile 无会话视图**：全新浏览器 profile 落在「新会话」空态——conversation view 不挂载，**标签条（对话/轨迹/代码图谱/ANIC）根本不存在**，标签计数 0 与插件无关。侧栏为 role=tree 结构：带 aria-expanded 的 treeitem 是工作区/分组行（点击展开），不带的才是会话行（点击打开视图）；「新会话」占位行打开空输入态不挂标签条，必须排除。
**修复**：探针检测无标签条时自动展开工作区树并代开第一个真实会话（不依赖宿主构建哈希类名，走 role=treeitem 结构语义）。

**验证**：两个防御各自构造前置场景实测——防御 A 在残留开关页面上运行 → `[清理]` 日志 + 8/8 PASS；防御 B 从空态运行 → `[兜底]` 日志 + 8/8 PASS。修复前同页面 4/8 FAIL。

### 2.3 P2-NTFS-TIMESTAMP：governance 测试 flake（迁移中满载暴露）

`tests/unit/governance.test.ts`「删过期 .tmp 文件」用 `tmpMaxAgeMs:-1` 踩 Windows NTFS 时间戳量化边界（mtime 可比 Date.now() 晚至 ~15.6ms，age 计算落在阈值内偶发红：独立跑 5/5 绿、满载并发跑 1 红）。
**修复**：`utimesSync(stale, past, past)` 把过期文件 mtime 钉到 60s 前 + `tmpMaxAgeMs: 30_000` 阈值远离边界。

### 2.4 P2-SMOKE-STALE-DIST：smoke 对 src 变更惰性（已知陷阱重现）

快照重生成改了 `src/client/workflowGraphData.ts`（169/217）而 dist 未重建 → smoke 4 FAILURE（旧 138/164 数据）。rebuild 后 ALL PASS。此陷阱已在父工程教训清单中（「smoke 读 dist 对 src 变更惰性」），本轮再次验证其真实性。
