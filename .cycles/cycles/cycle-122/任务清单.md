## §1 缺口定位（T1 证据）

`src/tools.ts`（修前 207 行）：

```ts
if (xuanjiPool) {
  const delta = computeGraphDiff(cached.nodes, cached.edges, merged.nodes, merged.edges);
  xuanjiPool.applyDelta(args.repoId, delta);   // ← PoolDeltaResult 被丢弃
}
```

`PoolDeltaResult` 携带 `applied / addedPaths / stalePaths / degradedRules / invariants(violated)`
——增量引擎降级与健康信号**生产了但没有消费面**：模型看不到、客户端看不到、UI 看不到。
