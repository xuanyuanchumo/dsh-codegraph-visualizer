## 任务分解（8个任务）

### TD-1: 修复面板重复渲染 (P0)
- **问题**: GraphPanel.tsx 754-800行(右侧栈)和802-850行(栈外)各渲染一次相同面板
- **方案**: 删除栈外的重复渲染代码(802-850行)，只保留栈内渲染
- **文件**: `src/client/GraphPanel.tsx`
- **测试**: 验证面板不重复出现

### TD-2: 修复 CyclePanel 条件不一致 (P0)
- **问题**: 栈内用 `cycleDetails.length > 2`，栈外用 `> 0`
- **方案**: 统一为 `> 0`（只要有循环就显示）
- **文件**: `src/client/GraphPanel.tsx`
- **测试**: 验证循环面板条件一致

### TD-3: 修复 FilterPanel 重置逻辑 (P1)
- **问题**: resetAll() 将 visibleNodeTypes/visibleEdgeTypes 清空(空Set=全部隐藏)，应改为全选
- **方案**: 重置时将 visibleNodeTypes/visibleEdgeTypes 设为所有类型的完整 Set
- **文件**: `src/client/components/FilterPanel.tsx`
- **测试**: 组件测试验证重置后所有类型可见

### TD-4: ImpactPanel/CyclePanel 增加关闭按钮 (P1)
- **问题**: 这两个面板没有关闭按钮，用户无法关闭
- **方案**: 添加 onClose prop 和关闭按钮
- **文件**: `src/client/components/ImpactPanel.tsx`, `src/client/components/CyclePanel.tsx`, `src/client/GraphPanel.tsx`
- **测试**: 组件测试验证关闭按钮

### TD-5: CoreFunctionPanel 颜色改用 CSS 变量 (P1)
- **问题**: CATEGORY_COLORS 使用硬编码 hex 颜色，主题切换时颜色不变
- **方案**: 改为使用 CSS 变量 `var(--cg-node-function)` 等
- **文件**: `src/client/components/CoreFunctionPanel.tsx`
- **测试**: 验证颜色使用 CSS 变量

### TD-6: 删除未使用的 SpatialIndex.ts (P2)
- **问题**: SpatialIndex.ts 与 QuadTree 功能重叠，未被任何控制器使用
- **方案**: 删除 SpatialIndex.ts 及其测试文件
- **文件**: `src/client/renderer/SpatialIndex.ts`, `tests/unit/SpatialIndex.test.ts`
- **测试**: 验证删除后所有测试通过

### TD-7: 移除 GraphPanel 重复 LOD 逻辑 (P2)
- **问题**: GraphPanel.tsx 中有独立的 LOD 计算，与 StyleController 重复
- **方案**: 移除 GraphPanel 中的 LOD 逻辑，统一由 StyleController 管理
- **文件**: `src/client/GraphPanel.tsx`
- **测试**: 验证 LOD 切换功能正常

### TD-8: ViewportController.destroy() 清理资源 (P2)
- **问题**: destroy() 方法为空，未清理 dimmedNodeIds
- **方案**: 在 destroy() 中清理 dimmedNodeIds 集合
- **文件**: `src/client/renderer/ViewportController.ts`
- **测试**: 单元测试验证清理
