## §5 设计决策登记

1. **重名歧义取第一候选**（非丢弃）：错配率 ≈ 重名占比（13/342≈4%）且被 ambiguous 计数暴露；丢弃会让 interface extends 增补在重名仓库整体失效。A2 测试钉住「确定性 + 可观测」契约。
2. **占位 target id + label 归并**（非遍历时序 nodeMap 查询）：walker 深度优先时子符号可能尚未入表，label 归并更稳健。
3. **merger 之后调用**（非适配器内）：merger 按 edge.id 合并，AST tsedge:* 与上游数字 id 永不相等——适配器内注入会绕过语义去重；增强器持有最终节点表可见全貌。
4. **全量路径限定**：增量轮的缓存已含上轮增强边，重复跑只会推高 duplicates。
5. **fingerprint 影响**：新增边 properties 含 edgeOrigin/edgeLocatable/targetName/line——按 cycle-119 §64.3 模式**不 bump FINGERPRINT.VERSION**（一次性 re-fingerprint 自愈）。
