## 二、非功能性需求评审

### 2.1 性能
- **模块大小**: 所有源文件 ≤ 226 行（上限 ~250），最大为 host/tools.ts
- **构建产物**: host 142.73KB + client 61KB，在 DSH 插件合理范围
- **测试执行**: vitest 153 tests 3.02s，smoke 19 checks <1s
- **虚拟视口阈值**: SCROLL_THRESHOLD 2500→500，对齐 LAYOUT.LARGE_NODE_THRESHOLD

### 2.2 可靠性
- **错误处理**: 所有外部调用 (ctx.get/localStorage/readdirSync) 均有 try-catch
- **资源清理**: ctx.effect 返回 disposer，所有路由注册跟踪清理
- **防御性编程**: ctx.get('tools', false) 非严格模式探测，不杀死 loading 中的 provider
- **无 `as any`**: 已修复为 `as SnapshotCtx` 类型安全断言

### 2.3 安全性
- **无 eval/exec**: 全代码库零动态执行
- **无 process.env**: 无环境变量直接访问，无密钥泄露风险
- **路径安全**: 工作区路径来自宿主服务 (registry/sessions)，非用户输入
- **脚本白名单**: skillInvoker 使用 isAllowedScript 白名单校验
- **CORS**: 响应带 buildCorsHeaders，桌面/远程 UI 跨源可见

### 2.4 可维护性
- **模块化纪律**: 一域一文件，路由按端点拆，特性模块制
- **日志规范**: scoped() logger from host/logger.ts，零直接 console
- **中文注释**: 所有注释中文，符合项目规范
- **ESM only**: `"type": "module"`，.ts 扩展名在 import

### 2.5 兼容性
- **DSH 多版本**: engines.dsh ">=0.2.0-rc.2 <0.4.0"，peerDependencies @deepseek-ai/cordis:^4.0.1
- **Node 版本**: engines.node ">=22.19"
- **平台**: dsh.client.platform "web"，web+desktop 共享同一 bundle
- **独立性**: G-IND 守卫 — dsh-anic 源码零 import 父项目 src/
