## 数据库评估结论

**不需要构建本项目自己的数据库系统。** 原因：
1. SQLite (CodeGraphAdapter) 已满足持久化需求
2. lastGraphData 内存缓存已完善
3. 客户端 IndexedDB + LRU 多层缓存已完整
4. DSH 平台约束 — 不应引入独立数据库
5. 参考项目验证 — Understand-Anything用JSON、Sourcetrail用SQLite

需要优化的方向：
- 服务端分片查询：内存过滤改为DB分页查询
- 增量索引：文件变更只更新对应文件
- IndexedDB扩展：增加outline/ast/edges缓存

## 多代适配器评估

当前 peerDependencies 已支持多代版本范围：
- `@deepseek-ai/dsh-client-connection: ^0.1.7-rc.2 || ^0.2.0-rc.2`
- `hostVersion: ">=0.1.1-rc.2 <0.3.0"`

需要为 v0.1.x 和 v0.2.x 的 API 差异创建专门适配器层，而非仅靠版本范围。
