## 研究结论汇总

### Better Sidebar 改进项
1. title 改为 `() => t('nav.title')` 函数形式支持 i18n 动态切换
2. visible=false 时主动停止 Cytoscape 动画帧、暂停数据轮询、取消网络请求

### Understand-Anything 可借鉴
1. graphology + graphology-communities-louvain 替代自定义图结构
2. 4 层验证管线（Sanitize → Normalize → AutoFix → Validate）
3. 别名映射系统提高数据容错性
4. Layer + Tour 双重组织
5. Core subpath exports 隔离

### Mermaid v12 评估结论
- 不适合替代 Cytoscape.js 作为主渲染器
- 推荐：增强现有 Mermaid 导出功能（v12 语义化形状、可折叠子图）

### 数据库需求
- 不需要构建自己的数据库
- 当前架构合理：Host 端只读 SQLite + 内存缓存，Client 端 IndexedDB + Zustand

### 前置插件依赖
- 设计合理，优雅降级已实现
- 可改进：增强独立运行体验（TreeSitterAdapter 批量扫描）
- 可改进：添加 FileSystemAdapter 填补无前置插件时的功能空白
