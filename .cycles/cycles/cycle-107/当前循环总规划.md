## 2. 范围与边界声明

- **目标**：把璇玑图规范实现为**零宿主依赖的算法库** `src/xuanji/`（可提取为
  `packages/xuanji`），并通过适配层接入真实宿主路径；同时落地两份优化方案中的
  P0–P2 项（Booth / 多重边 / 增量缓存 / 规则共享遍历 / 输出敏感可达）。
- **范围**：`src/xuanji/**`（新库）、`src/shared/analysis/XuanjiAdapter.ts`（适配层）、
  `src/tools.ts`（`graph_path_enumerate` 工具 = 库的真实可达调用方）、
  `AdjacencyCache` / `RuleEngine` / `CoreFunctionAnalyzer` / `CycleDFS` 内部实现替换。
- **排除**：不建 pnpm workspace（单包仓库 + tsdown 构建，建 workspace 属另一轮基建）；
  不替换 `CycleDetector` 的环枚举语义（DFS 基本环组 vs 全部简单环，语义不同，
  替换会造成行为回归）；不引入 NFA 全量乘积（`compileLengthNfa` 只做长度维度抽象）。
- **诚实偏差**：增量引擎未使用 spec §5.2 的「前缀桶 × 后缀桶」配对（该配对在
  `lMin ≥ 2` 与 `closed` 规则下**不完备**——前缀/后缀短于 lMin 时不入桶）；改用
  「旧图反向 DFS 前缀 × 新图正向 DFS 后缀 + isLegalPath 精确终判 + workBudget 降级」。
  见 `src/xuanji/index/incremental.ts` 模块注释与 `tests/unit/xuanji/incremental.test.ts` 顶部声明。
