## 2. 性能验证

测量口径：`node scripts/bench-xuanji.mjs`（单进程、无并行测试干扰；
数字为一次运行的毫秒值，用于数量级对照而非门禁）。

| 场景 | 规模 | 基线实现 | 新实现 | 结论 |
|---|---|---|---|---|
| 全图可达计数 | 3000 节点 / 5999 边 | 逐节点截断 BFS **139.7 ms** | SCC+bitset 闭包 **9.1 ms** | **15.4×**；且新值为精确可达数（旧值被 500 截断） |
| 单边增量（50 条） | 800 节点 / 1600 边，closed 规则 lMax=4 | 更新后整图重枚举 **14.7 ms** | `onEdgeAdded` ×50 **2.2–4.6 ms** | **3.2–6.7×**；成本随「经过新边的路径数」而非图规模增长 |
| 路径读法（工具一次调用） | 1200 节点 / 4797 边，maxHops=5 | 旧 `graph_path_find` 只给一条最短路 | `findPathsBetween` 返回 11 条不同路径 **4.2 ms** | 同等规模下可交互（<10 ms），上限由 `limit`/跳数守卫 |

## 3. 内存稳定性

| 项 | 观测 | 结论 |
|---|---|---|
| 索引内存 | 每个已注册规则一套 `PathIndex`；条目只在「规则物化路径」时增长，`workBudget` 超限整索引清空 | 有界 |
| 增量降级 | `INCREMENTAL_WORK_BUDGET = 50 000` 次展开；超限 `index.clear()` 并返回 []，由下次查询全量枚举 | 不会因稠密邻域卡死 |
| 长链 | `batchReach` 用迭代式 Tarjan + 定长 `Uint32Array`，无递归爆栈（601 长链用例） | 稳定 |
| 泄漏面 | 库内无可变模块级单例；`GraphSpace.clear()/PathIndex.clear()` 全量释放 | 无新增泄漏点 |

## 4. 安全验证

| 检查项 | 结果 | 备注 |
|---|---|---|
| 输入校验与过滤 | 通过 | `validateRule` 拒绝非法规则；工具层 `minHops/maxHops/limit` 夹紧（1–10 / 1–50）、未知边类型回退默认读法；未知节点返回 null |
| 防 XSS | 不适用/通过 | 库无 DOM；工具 render 只输出节点 id 文本 |
| 路径穿越防护 | 不适用 | 库不接触文件系统 |
| 敏感数据不泄露 | 通过 | 库不读环境变量、不写日志；适配层只转译 GraphData |
| 动态代码 | 通过 | 库内无 `eval`/`new Function`/动态 import（源码扫描契约只允许相对导入） |
| 依赖审计 | 未执行 | 审计端点不可用（npmmirror 无 `/-/npm/v1/security/audits`）；cycle-106 Q4 同类 carry-over |
