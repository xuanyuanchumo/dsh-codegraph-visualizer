## 4. 执行策略

### 4.1 优先级排序

1. **P0-1~P0-6**: 测试覆盖率修复（G2门禁阻塞，必须先做）
2. **P1-1**: 适配器接口（cycle-1遗留的技术债务）
3. **P1-2**: 上下文菜单（用户体验提升）
4. **P1-3**: 语义化颜色编码（视觉效果增强）
5. **P2-P3**: 视条件推进

### 4.2 并行执行计划

- P0-1~P0-6 可并行派遣（6个独立文件的测试补充）
- P1-1~P1-3 在 P0 完成后并行执行

### 4.3 验证策略

1. 每完成一个 P0 任务，运行 `vitest run` 验证
2. 所有 P0 完成后，运行 `vitest run --coverage` 验证覆盖率达标
3. P1 完成后，运行 `pnpm run typecheck && pnpm run lint` 验证
4. 全部完成后，构建插件并在 DSH 环境验证
