## 4. 修复明细（tests/e2e 基础设施，两项连带修复）

### 4.1 waitForVisualStable 参数丢失（潜伏 cycle-93-101）

| 项 | 内容 |
|---|---|
| 症状 | 全部 visual 用例 TimeoutError page.waitForFunction 15000ms（helpers.ts:716），页面实际已稳定（debug 采样 15/16 帧字节级一致） |
| 根因 | Playwright 1.62 `waitForFunction(pageFunction, arg, options)` 只转发一个 arg（types/types.d.ts 两处重载均单 arg；node -e 实证 5 参调用只收到 {settle:300}）；b177ae6 把调用改成 4/5 参 → `document.querySelector(undefined)` → null → poll 永远 false → 静默超时 |
| 波及面 | J4 call chain 等全部既有用例同超时（非新用例独有）；cycles 93-101 未跑 visual 套件所以未暴露 |
| 修复 | helpers.ts 两处 waitForFunction 均改单对象参数 `(args: {settle, panelSel, containerSel})` / `(args: {settle, containerSel})` |
| 验证 | 全量 9/9 用例过 + e2e-14 三跑严格比对绿 |
