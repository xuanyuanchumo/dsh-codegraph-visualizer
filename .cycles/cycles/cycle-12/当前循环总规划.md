## 任务分解（10个任务）

### TD-1: LOD class 切换性能优化 (P0)
- **问题**: StyleController.applyStylesheet() 每次 LOD 切换都 fromJson 重建全量样式表
- **方案**: 预计算三档样式表，LOD 切换时用 addClass/removeClass 替代 style().fromJson().update()
- **文件**: `src/client/renderer/StyleController.ts`
- **测试**: 新增 LOD class 切换性能测试

### TD-2: Cytoscape 性能配置优化 (P0)
- **问题**: 缺少 hideEdgesOnViewport, hideLabelsOnViewport 配置
- **方案**: 在 CytoscapeRenderer.init() 中添加性能配置项
- **文件**: `src/client/renderer/CytoscapeRenderer.ts`
- **测试**: 验证配置项正确传递

### TD-3: fCoSE 大规模布局参数调优 (P0)
- **问题**: fCoSE 布局对大规模图未使用 quality:'draft' 和减少迭代
- **方案**: 根据 nodeCount 动态调整 fCoSE 参数
- **文件**: `src/client/renderer/LayoutController.ts`
- **测试**: 验证不同 nodeCount 下参数正确

### TD-4: 大规模阈值常量调整 (P0)
- **问题**: VIRTUAL_VIEWPORT.SCROLL_THRESHOLD=2000, CLUSTER.MAX_VISIBLE_NODES=2000 过低
- **方案**: 提高阈值，SCROLL_THRESHOLD→5000, MAX_VISIBLE_NODES→5000
- **文件**: `src/shared/constants.ts`
- **测试**: 验证新阈值下虚拟视口和聚类行为

### TD-5: 多面板位置管理 (P1)
- **问题**: path-bar/health-score/rule-panel 等面板都在 left:12px 导致重叠
- **方案**: 实现面板位置栈管理，打开新面板时自动避让已打开面板
- **文件**: `src/client/GraphPanel.tsx`, `src/client/hooks/usePanelState.ts`, CSS
- **测试**: 组件测试验证面板不重叠

### TD-6: API 速率限制 (P1)
- **问题**: API 端点无速率限制，计算密集型端点可被滥用
- **方案**: 实现简单的 IP+路径速率限制中间件
- **文件**: `src/host/routes.ts`, `src/host/security.ts`
- **测试**: 单元测试验证速率限制生效

### TD-7: 事件命名空间迁移 cg-viz/ (P1)
- **问题**: codegraph/ 事件命名空间与上游 dsh-codegraph 完全重叠
- **方案**: 将所有 codegraph/ 事件前缀改为 cg-viz/
- **文件**: `src/types/index.ts`, `src/client/GraphPanel.tsx`, `src/host/watcher.ts`
- **测试**: 验证事件命名空间正确

### TD-8: 微视图入口可发现性 (P1)
- **问题**: 微视图按钮只在选中 function 类型节点时才显示
- **方案**: 在 NodeDetail 中增加微视图入口提示，在 Toolbar 中增加微视图快捷入口
- **文件**: `src/client/components/NodeDetail.tsx`, `src/client/components/Toolbar.tsx`
- **测试**: 组件测试验证微视图入口可见

### TD-9: 核心组件测试补全 (P1)
- **问题**: Toolbar, ImportPanel 缺少组件测试
- **方案**: 为 Toolbar 和 ImportPanel 编写组件测试
- **文件**: `tests/component/Toolbar.test.tsx`, `tests/component/ImportPanel.test.tsx`
- **测试**: 新增组件测试

### TD-10: 虚拟视口边裁剪增强 (P2)
- **问题**: VirtualViewportController 只裁剪节点，边通过节点可见性间接判断
- **方案**: 增加边的独立视口裁剪逻辑，对跨视口长边渲染截断指示器
- **文件**: `src/client/renderer/VirtualViewportController.ts`
- **测试**: 单元测试验证边裁剪逻辑
