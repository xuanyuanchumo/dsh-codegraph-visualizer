## 5. 事实基座抽验（6 项）

1. `src/host/HttpHelpers.ts:74-92` buildCorsHeaders：expose-headers `'etag, x-truncated'`、allow-headers `'content-type, if-none-match'`、allow-origin 仅白名单精确匹配时写入、vary Origin、max-age 86400。
2. `src/host/HttpHelpers.ts:94-100` handleCorsPreflight：OPTIONS → 204 + buildCorsHeaders。
3. `src/host/HttpHelpers.ts:109-124` sendJson：buildCorsHeaders + extraHeaders 合并（etag 必须走 sendJson，直接 writeHead 会漏 CORS 头——HttpHelpers.ts:102-106 注释）。
4. `src/host/routes/shared.ts:196-211` checkEtag：304 分支回写 buildCorsHeaders + etag——304 也带全套 CORS 头（本轮单测核心断言点）。
5. `cordis.patch.yml:18-20`：`config.allowedOrigins = ['http://localhost:3080', 'http://127.0.0.1:3080']`（"Config is explicit (red line 9)"）。
6. `tests/unit/routes.test.ts` 新 describe（cycle-101）：5 例断言 200 回显 / 白名单外不回显 / 304 全套头 / 304 语义不变 / 预检 if-none-match。
