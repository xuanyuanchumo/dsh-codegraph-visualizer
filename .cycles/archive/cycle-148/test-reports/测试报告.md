## 3. 本循环修复的缺陷（dsh-anic 生命周期工具）

| 项 | 内容 |
|---|---|
| 症状 | init-cycle 在 146 循环全部归档后创建 `cycle-1`（编号回落） |
| 双重后果 | ① archive/cycle-1 名字已被古档占用 ⇒ archive-cycle 永久 BLOCKED；② currentCycle=146 拒收回拉 ⇒ 状态机与目录脱节 |
| 根因 | `getNextCycleNum` 只扫活跃区 `.cycles/cycles/`（归档收口态合法为空）⇒ 返回 1 |
| 修法 | 活跃区 + 归档区 + workflow-state.currentCycle **三处取最大再 +1**；三处皆无信息才回落 1；`--cycle N` 显式旗标仍最高优先；损坏状态 JSON 走 catch 不参与取数 |
| 提交 | dsh-anic `5a93b53`（+37/-6）；技能副本经 anic_skill_repair 同步（dualTrack in-sync） |
