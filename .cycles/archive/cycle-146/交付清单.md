### 发布过程缺陷记录（诚实登记）

1. **vault_run cwd 陷阱**：vault_run 的子进程 cwd 是 desktop profile（package.json 无 version 字段）→ npm 11 `semver.parse(undefined).prerelease` 抛 `Cannot read properties of null`。根因不是 token 而是执行目录——修复为项目内包装脚本 + `--userconfig`。
2. **Windows 环境变量注入限制**：`NPM_CONFIG_//registry.npmjs.org/:_authToken` 键名含斜杠在 Windows 不可设 → vault 的 env 注入到不了 npm 配置层。修复：脚本内写项目级临时 .npmrc（token 不打印、用完即删）。
3. **prepublishOnly 超时**：build+test 全量 >120s 超过 vault_run 工具超时 → 首次调用超时但服务端实际完成发布（幂等冲突 `cannot publish over 0.3.0` 即证据）。后续发布应拆分：构建/测试已在门禁闭环，publish 只发产物（--ignore-scripts）。
