## 8. 诚实披露

1. **真实 git 子进程测试**：6 条用例起真实 git 进程 + 临时仓库（非 mock）——慢（~5s）但能抓格式漂移；
   首跑在并行负载下偶发 1 次失败（复跑全绿），若再复发应给往返用例加 `--pool=forks` 隔离。
2. **逐文件 blame 的吞吐**：大仓库（数千文件）单次采集会串行跑数千个 git 进程（每个 ~10ms），
   TTL 缓存摊平后首查可能秒级——gitSources.durationMs 会如实披露这个成本；若真机过慢，
   流转「按最近提交时间窗口裁剪 blame 文件集」优化项。
3. `ops_stat`/`ops_bash` 的 PUBLICATION_DENIED 与 shell 偶发超时是本轮会话基建问题（不影响产物），
   按 nextAction 改用 bash 工具与 read+edit 重试，全部绕过成功。
